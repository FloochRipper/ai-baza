# Стартовый набор для Claude Code
## Всё что нужно установить чтобы начать работать полноценно

---

## Что такое скиллы и плагины

**Скиллы** — это готовые инструкции для Claude. Ты пишешь `/carousel` и Claude уже знает как делать карусель для Instagram, со всеми правилами и форматами.

**Плагины** — расширения самого Claude Code. Дают новые возможности: браузер, память, работу с файлами.

---

## Блок 1 — Обязательные плагины (устанавливаются один раз)

### Superpowers — главный плагин
Даёт доступ ко всей системе скиллов. Без него ничего не работает.

```bash
# В чате Claude Code напиши:
/install superpowers
```

Что получаешь сразу после установки:
- Планирование и выполнение задач
- Работа с кодом (review, debug, test)
- Генерация контента для соцсетей
- И все остальные скиллы ниже

---

### Context7 — актуальная документация
Автоматически подгружает свежую документацию любого инструмента когда ты с ним работаешь.

```bash
/install context7
```

---

### Playwright MCP — браузер для Claude
Claude может открывать сайты, нажимать кнопки, заполнять формы.

```bash
npm install -g @playwright/mcp@latest
```

**Важно: как не сжигать токены зря**

Playwright по умолчанию делает скриншот на каждый шаг — это дорого. Есть хитрость: когда нужно собрать данные с сайта (например, скачать много страниц), скажи Claude:

> "Используй fetch() внутри браузера чтобы загрузить все страницы параллельно и сохрани результат в файл"

Так Claude загружает 20-100 страниц за один запрос, без скриншотов, и сохраняет прямо на диск — не в чат. Токены почти не тратятся.

Playwright MCP нужен напрямую только когда надо кликать и логиниться. Для сбора данных — всегда используй fetch() внутри браузера.

После установки Superpowers эти скиллы активируются командой `/название`:

| Telegram | `/telegram` | Пост для Telegram-канала |

| Threads | `/threads` | Ветка постов-тезисов |
| Копирайтер | `/copywriter` | Усилить текст, хук, CTA |
| Контент-план | `/content-strategist` | План на неделю/месяц |
| Лид-магнит | `/lead-magnet` | Структура и контент лид-магнита |
| Анализ конкурента | `/competitor-analysis` | Разбор чужого контента |
| Продуктовая стратегия | `/product-strategist` | Анализ ЦА, воронки, сегменты |

## Блок 4 — Дополнительные инструменты

### Marker — конвертер PDF в текст
Экономит 30-40% токенов. Вместо того чтобы читать PDF — конвертирует в чистый текст.

```bash
pip install marker-pdf
# Использование:
marker_single документ.pdf output/
```

### Memory Bank — долгосрочная память
Claude помнит контекст между сессиями. Альтернатива: просто используй CLAUDE.md (уже встроено).

## Как это выглядит на практике

1. Открываешь VS Code
2. Открываешь папку проекта
3. Открываешь чат Claude Code (Shift+Cmd+Esc на Mac)
4. Пишешь `/telegram` — и Claude уже знает как писать в твоём стиле
5. Получаешь готовый пост

Голосом — если установлен Aquavo Voice ($10/мес): нажимаешь горячую клавишу, надиктовываешь, текст вставляется в чат.
