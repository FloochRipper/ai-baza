Словарь терминов
Всё что встретится на пути простыми словами
📖 Термины ▼
LLM
Большая языковая модель. Claude, ChatGPT, Gemini — это LLM
Промпт
Ваш запрос к AI. Главный инструмент получения нужного результата
R.A.C.E.T.
Формула промпта: Role, Action, Context, Expectation, Tone
Токен
Единица обработки текста AI. Ориентир — 1 слово ≈ 1-2 токена
Агент
AI со специализацией и автономией. Делает цепочку шагов сам
Скилл
Готовая инструкция на конкретную задачу. Вызывается через /команду
Плагин
Расширение Claude Code. Ставится один раз, даёт новые возможности
MCP
Model Context Protocol — способ подключать к Claude внешние инструменты
CLAUDE.md
Файл правил проекта. Claude читает при каждом запуске сессии
Git / Commit
Сохранение версии. Как чекпоинт в видеоигре
Push
Отправка сохранений в облако (GitHub). Защита от поломки компа
Фронтенд
Всё что видит пользователь: кнопки, тексты, картинки
Бэкенд
Внутренняя логика: данные, авторизация, обработка
API
Способ программ общаться между собой
Деплой
Публикация сайта или приложения в интернет
MVP
Минимальная рабочая версия продукта. Самокат прежде чем строить машину
