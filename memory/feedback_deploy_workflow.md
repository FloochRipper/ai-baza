После каждой осмысленной партии правок в `baza-znaniy` я сам делаю git commit + git push origin main. Netlify связан с репо github.com/FloochRipper/baza-znaniy и деплоит автоматически из main.

**Why:** Никита хочет видеть изменения сразу на продакшене (classy-cactus-6e633a.netlify.app), а не просить отдельно. Без пуша мои правки на локальный index.html не видны на сайте.

**How to apply:**
- Работаю партиями — написал 2-4 раздела / завершил логичный кусок → сразу коммит+пуш
- Не коммить каждую мелочь (не нужно 10 коммитов за сессию)
- Commit-сообщение в стиле прошлых коммитов репо: на русском, описывает суть изменений
- Не спрашиваю разрешения каждый раз — это разрешённое действие в этом проекте
- Если пользователь явно попросил "ничего не пушить" или "только локально" — не пушу
