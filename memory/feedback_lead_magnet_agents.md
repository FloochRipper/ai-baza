## Лид-магнит = готовая система AI-агентов, не просто промпты

Двухуровневый лид-магнит:
- Уровень 1: промпты для claude.ai (порог входа ноль)
- Уровень 2: папка со скиллами для Claude Code (персональный AI-ассистент)

**Why:** Промпты - слабая тема, одноразовые. Система агентов - это уникальное предложение, отстройка от всех кто раздаёт "паки промптов". Показывает разницу между "потыкать ChatGPT" и "построить систему".

**How to apply:**
- CTA в контенте: "не промпты, а готовая модель агентов"
- Контентная цепочка: Reels 1 (ценность системы) → Reels 2 (как установить за 5 минут)
- Структура лид-магнита: CLAUDE.md + skills/ (content-plan, competitor, sales-script, copywriter, finance)
- Человек заполняет CLAUDE.md (имя, ниша, продукт, аудитория) → получает персонального AI-ассистента

Папка вынесена из рабочего проекта в /Users/mac/Documents/Projects/lead-magnet-agents/ чтобы не путать Claude Code при работе над контентом.
