2026-04-14 — прогнали три варианта дизайна базы знаний через worktree:

- **orange-plus** (выбран как основной) — фирменный тёмный #0a0a0a + оранжевый #F5521A, Bebas Neue + Montserrat. Сохраняет связь с контент-заводом и 100-prompts-pro. Мёржим в main.
- **editorial** — кремовый фон + serif Fraunces + coral. Отложен.
- **neon-dark** — глубокий тёмно-серый #0e0e10 + violet #8b5cf6, Inter/Geist, glassy-карточки, ⌘K-палитра. Никите понравилась СТРУКТУРА (а не сама палитра).

**Что именно из neon-dark стоит перенести в orange-plus при следующем ревизии:**

- ⌘K command palette вместо простого инпута поиска (быстрее для power-users, Никита с клавиатурой дружит через Wispr Flow, паттерн ему близок)
- Двухколоночный hero (текст слева + author-card справа) — более выразительный чем плоский блок снизу
- Hero-карточки блоков с крупной типографикой "BLOCK 01 / Основы AI" — читается как SaaS-продукт
- Glass-эффекты на топнаве (backdrop-blur) — добавляют премиальности без смены цветовой палитры
- SVG-chevron'ы вместо ▼-эмодзи — чище смотрится

**Why:** Никита явно сказал "neon-dark нравится по структуре, запомни". Не сам цвет, а композиция и паттерны. Оранжевый брендинг остаётся железобетонным.

**How to apply:** Когда база дорастёт до v2 или появится причина освежить UX (например прирост аудитории, рост числа секций >40, жалобы на поиск) — пересмотреть orange-plus и подтянуть перечисленные паттерны из ветки `worktree-neon-dark`. Сама ветка сохраняется в репо как архив.

Ветка с neon-dark не удалена, храним для будущих референсов: `git checkout worktree-neon-dark`.
