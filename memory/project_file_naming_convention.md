В разделе базы знаний "Архитектура проекта в Claude Code" используем **свою конвенцию именования**, не курса Вайбкодинг:

- `CLAUDE.md` — правила работы
- `PLAN.md` — план этапов
- `CONTEXT.md` — паспорт проекта (в курсе это называется `project.md`)

**Why:** Никита не хочет чтобы контент выглядел скопированным из курса Нейроуниверситета. CONTEXT.md — название с понятной функцией ("контекст проекта") и личным почерком.

**How to apply:** Когда пишу раздел про архитектуру проекта или примеры структуры папки — везде `CONTEXT.md`. Курсовое имя `project.md` не упоминаем. В реальном репо baza-znaniy у нас уже лежит CONTEXT.md — это будет живым примером.
