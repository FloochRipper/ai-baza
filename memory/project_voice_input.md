В базе знаний обязательно должен быть раздел про **голосовой ввод** как способ общаться с Claude (и в claude.ai, и в Claude Code).

Рекомендуемые приложения:
- **Wispr Flow** — работает в любом приложении, горячая клавиша, моментальная транскрипция
- **AquaVoice** — альтернатива

**Why:** Никита сам пользуется этим и считает критичным — через голос общение с Claude в разы быстрее, чем печатать. Это одна из ключевых фишек его рабочего процесса, а не просто удобство.

**How to apply:**
- Включить в базе знаний как отдельный пункт (или мини-раздел)
- Уместно в блоке 1 (применимо с первого дня с claude.ai) плюс упоминание в блоке 2 (работа с Claude Code тоже через голос)
- Не "можно использовать" а прямо "рекомендую, сам так работаю"
