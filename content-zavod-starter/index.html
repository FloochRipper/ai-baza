Что такое контент-завод

Контент-завод — это моя система, которая превращает одно видео конкурента в готовый сценарий, пост и карусель на три соцсети. Я не делаю контент "по вдохновению" — у меня работает конвейер.

Система состоит из нескольких блоков: парсинг конкурентов → анализ паттернов → адаптация под свой голос → раскладка по форматам (Reels, Telegram, карусели, Threads) → визуал.

На этой странице — только первый блок: парсинг Reels. С него начинается любой цикл. Делюсь им бесплатно, потому что без этой базы остальное бессмысленно: ты должен понимать что реально работает у твоей ниши, а не гадать.

Как запустить

Три шага. Даже если раньше ты в глаза не видел ни Claude Code, ни VS Code — пройдёшь за 10-15 минут.

1
Поставь Claude Code

Claude Code — это не сайт, а расширение внутри редактора VS Code. Качаешь VS Code, ставишь два расширения, авторизуешься. Минут пять и всё готово.

Если ты из России — обязательно под VPN

Весь процесс установки и работы делай под VPN. Без него не откроется claude.ai, не пройдёт логин через Anthropic, и Claude Code не получит доступ к API. VPN нужен и при первой настройке, и каждый раз когда работаешь с Claude.

  1. Скачай VS Code: code.visualstudio.com. Бесплатный редактор от Microsoft под Mac, Windows, Linux.
  2. Для Windows важно: при установке поставь галку "Add to PATH". Без неё Claude Code не запустится.
  3. Открой VS Code. Слева иконка расширений (или сочетание клавиш Cmd+Shift+X на Mac / Ctrl+Shift+X на Windows). В поиске набери russian, поставь "Russian Language Pack" от Microsoft. Перезапусти VS Code — интерфейс станет на русском.
  4. Снова открой расширения, в поиске набери claude code. Поставь "Claude Code" от Anthropic.
  5. Слева появится иконка Claude. Нажми её — откроется браузер для авторизации. Войди через аккаунт Anthropic (тот же что на claude.ai).
Нет аккаунта Anthropic?

Зарегистрируйся на claude.ai — бесплатно. Потом возвращайся к шагу 5.

Что нужно по деньгам:

  • Claude Pro или Max — подписка $20 или $100-200/мес. На Pro можно начать, для серьёзной работы лучше Max.
  • Аккаунт GitHub — бесплатный. Нужен для сохранения проектов в облако (пригодится позже).

Не получилось? Напиши в Telegram @nikitashlyk — проведу по установке персонально.

2
Создай папку проекта и распакуй скилл
  1. Открой Finder (Mac) или Проводник (Windows). Зайди в Документы, создай новую папку. Назови её content-zavod.
  2. Найди скачанный архив content-zavod-starter.zip (обычно в папке Загрузки). Двойной клик — распакуется.
  3. Внутри распакованного архива папки .claude и scripts. Перетащи их целиком в свою папку content-zavod.

Должно получиться так:

content-zavod/
├── .claude/
│   └── skills/
│       └── content-zavod/
│           ├── SKILL.md
│           └── README.md
└── scripts/
    ├── process_reels.sh
    └── reels_urls.txt
Если запутался

Можешь открыть папку content-zavod в VS Code, нажать иконку Claude и написать: "Распакуй мне скилл из архива в Загрузках в этот проект правильно". Claude сам разложит файлы по местам.

3
Скажи Claude Code разобрать Reels
  1. В VS Code: Файл → Открыть папку → выбери content-zavod.
  2. Слева нажми иконку Claude — откроется чат.
  3. Напиши команду и вставь ссылки:
разбери мне Reels:
https://instagram.com/reel/ABC/
https://instagram.com/reel/DEF/
https://instagram.com/reel/GHI/

Что дальше Claude делает сам:

  • Проверит что установлено из инструментов, чего не хватает — поставит
  • Скачает модель whisper для транскрипции (один раз, 547MB)
  • Скачает каждый Reels, преобразует аудио, распознает речь в текст
  • Соберёт всё в один markdown-файл с автором, датой, длиной ролика и транскриптом
  • Доложит результат

Через 10-15 минут у тебя на руках корпус транскрипций. Лежит в knowledge/reels-corpus/transcripts.md.

Это только транскрипция. Дальше — самое интересное.

Собранный корпус — это сырьё. Когда он готов, ты говоришь Claude Code простые фразы — и получаешь результаты, ради которых всё и затевалось.

Найти рабочие паттерны
разбери корпус, найди какие хуки повторяются чаще
Claude прочитает все транскрипты, выделит топ-10 работающих хуков, типичные структуры, CTA. Получаешь карту приёмов которые уже доказанно залетают в твоей нише.
Адаптировать чужой сценарий под себя
возьми ролик ABC, переделай сценарий под мою подачу и нишу
Claude берёт структуру чужого Reels, переписывает текст под твой голос и твою аудиторию. У тебя на выходе — готовый сценарий на съёмку, построенный на том что работает.
Сгенерить новый Reels на базе паттернов
собери Reels на тему X с самым сильным хуком из корпуса
Получаешь 3 варианта хука, полный тайм-код, визуальные пометки для монтажа. Снимаешь и публикуешь.
Собрать контент-план на неделю
построй контент-план на 7 дней на базе этого корпуса
Недельный план с Reels, постами в Telegram и ветками Threads. Каждая единица опирается на структуру которая уже доказала свою виральность.
