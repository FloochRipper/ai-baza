# Контент-завод — разбор Reels конкурентов

Ты помогаешь пользователю собирать корпус транскрипций Reels конкурентов для анализа паттернов. Всё работает локально на Mac — без API-ключей, бесплатно.

## Когда срабатываешь

Триггеры:
- "разбери мне Reels" + список ссылок
- "прогони через пайплайн"
- "транскрибируй эти ролики"
- Пользователь прислал 2+ ссылок на `instagram.com/reel/...`

## Что делаешь пошагово

### Шаг 1 — Проверь установлены ли инструменты

Запусти в Bash:
```bash
which yt-dlp ffmpeg whisper-cli jq
```

Если какой-то из инструментов не установлен — поставь через brew:
```bash
brew install yt-dlp ffmpeg whisper-cpp jq
```

### Шаг 2 — Проверь наличие модели whisper

Модель должна лежать в `.models/ggml-large-v3-turbo-q5_0.bin` в рабочей папке.

Если нет — скачай:
```bash
mkdir -p .models
curl -L -o .models/ggml-large-v3-turbo-q5_0.bin \
  "https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3-turbo-q5_0.bin"
```

Это ~547MB, займёт 1-2 минуты. Скачивается один раз.

### Шаг 3 — Убедись что есть скрипт process_reels.sh

Он должен лежать в `scripts/process_reels.sh`. Если нет — скажи пользователю что скилл установлен неправильно, попроси его переустановить.

### Шаг 4 — Собери URL от пользователя

Если пользователь прислал ссылки прямо в чат — запиши их в `scripts/reels_urls.txt`, по одной на строку. Дедуплицируй (одинаковые URL не повторяй).

Если ссылок мало (1-3) — сразу запускай. Если много (10+) — уточни у пользователя: "Готов прогнать N ссылок, примерно столько-то минут, запускаем?".

### Шаг 5 — Запусти пайплайн

```bash
cat scripts/reels_urls.txt | bash scripts/process_reels.sh
```

Мониторь вывод. Для каждого URL будет одна из меток:
- `[OK]` — успешно
- `[SKIP]` — уже в корпусе (дубль)
- `[FAIL]` — не удалось скачать (приватный/удалённый пост)

### Шаг 6 — Доложи результат

Когда пайплайн закончил, проверь итог и скажи пользователю:
- Сколько обработано
- Сколько пропущено (дубли)
- Сколько ошибок (и какие URL)
- Где теперь лежит корпус: `knowledge/reels-corpus/transcripts.md`
- Сколько всего записей в корпусе

Предложи следующий шаг:
- Если записей мало (<20): "Пополняй корпус новыми ссылками"
- Если достаточно (20+): "Могу запустить агента разобрать паттерны"

## Важные правила

- **Никогда не модифицируй скрипт `process_reels.sh`** — он оттестирован.
- **Не меняй структуру `transcripts.md`** — формат стандартизирован.
- Если видишь что язык Instagram-ролика не RU и не EN, предупреди: whisper может ошибаться на экзотических языках.
- **Следи за свободным местом** — 37 роликов это ~100MB mp4. Предупреди если диск забит.

## Где хранится результат

- `downloads/competitors/<ID>.mp4` — оригинальные видео (для пересмотра)
- `knowledge/reels-corpus/transcripts.md` — главный корпус, единый markdown
- `knowledge/reels-corpus/metadata.json` — автор, просмотры, лайки, дата
- `knowledge/reels-corpus/process.log` — лог обработки

## Как ответить если пользователь просит анализ после транскрипции

Если пользователь после транскрипции говорит "найди паттерны", "какие хуки работают", "сделай разбор" — прочитай `transcripts.md`, выдели:
1. Топ-10 хуков (первые 3-5 сек каждого ролика)
2. Типичные структуры (туториал / список / сравнение / провокация)
3. CTA-паттерны (какие кодовые слова, какие обещания в директ)
4. Различие RU vs EN стилей (если корпус смешанный)

Результат сохрани в `knowledge/reels-corpus/patterns_analysis.md`.
