## Структура лейаута (финальный дизайн v7)

Три колонки на статье:

```
[TOP NAV — горизонтально, глобальные разделы]
┌─────────────────────────────────────────────┐
│  Лого · nav · nav · nav · nav · nav          │
├──────────┬──────────────────────┬────────────┤
│  LEFT    │  CENTER              │  RIGHT     │
│  170px   │  1fr                 │  160px     │
│          │                      │            │
│  Раздел  │  Breadcrumbs         │  На этой   │
│  Блок    │  H1 + Copy btn       │  странице  │
│  (список │  Текст + блоки       │  (якоря)   │
│  стр.    │  Prev/Next           │            │
│  блока)  │                      │            │
└──────────┴──────────────────────┴────────────┘
```

- **Top nav:** логотип + горизонтальные разделы (Для новичка / Claude Code / Контент-система / …)
- **Left sidebar:** список страниц текущего блока (не глобальные разделы — они уже вверху). Фиксированный при скролле
- **Center:** хлебные крошки, заголовок, статья, контентные блоки, prev/next пагинация
- **Right TOC:** якоря текущей статьи. Фиксированный при скролле
- На мобиле: left + right убираем, центр на всю ширину

## Контентные блоки

Все переиспользуемые компоненты статьи:

| Блок | CSS-класс | Назначение |
|------|-----------|------------|
| Ключевой факт | `.callout.key` | Белый фон, оранжевая полоса слева |
| Аналогия | `.callout.analogy` | Кремовый фон |
| Предупреждение | `.callout.warn` | Кремовый фон, чёрная полоса слева |
| Карточки-сетка | `.grid-5` | R.A.C.E.T. и аналогичные |
| Сравнение | `.compare` | Плохо vs хорошо, две колонки |
| Код/промпт | `.codeblk` | Тёмный фон, кнопка «Копировать» |
| Таблица | `.tbl` | Mono-заголовки, тонкие линии |
| Pager | `.pager` | Prev/Next статьи внизу |

Inline-маркер: `.marker` — жёлто-оранжевый градиент под словом.

## SEO-подход

- Каждый подраздел = отдельный HTML-файл (`/block-00/ai-llm-neurons.html`)
- `<title>`, `<meta description>`, `<meta og:*>` на каждой странице
- JSON-LD (Article) на каждой статье
- `sitemap.xml` в корне
- `llms.txt` для AI-краулеров

---

## MVP-рамки

Делаем по порядку:

1. **Шаблон** — один HTML-файл с тремя колонками, всеми CSS-переменными и компонентами
2. **Нулевой блок** — 10 страниц по схеме выше, полное содержание
3. **Главная** (`index.html`) — хаб, карточки разделов, CTA
4. **Деплой** — Vercel, sitemap, llms.txt
5. **Остальные блоки** — по мере готовности

Монетизация и доступы — отдельная задача позже, не в этом MVP.
