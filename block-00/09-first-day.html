Что сделать в первый день

Конкретный список без лишних слов. Выполни всё — и у тебя будет рабочая настройка, а не просто аккаунт.

Чек-лист первого дня

1. Зарегистрируйся на claude.ai

Если ты из России — нужен VPN и иностранный номер. Подойдут Outline, Mullvad или любой другой VPN. Для номера — sms-activate.org или 5sim.net.

2. Выбери тариф

Начни с Free. Если почувствуешь лимиты — переходи на Pro ($20/мес). Max нужен только при интенсивной работе с кодом.

3. Создай первый Project

Назови по задаче, которую решаешь чаще всего: «Контент», «Мой бизнес», «Клиент Х». Напиши в Project Instructions 3–5 предложений: кто ты, чем занимаешься, что важно. Это всё.

⚡ Главный шаг

Project с инструкциями — это базовая настройка. Без неё ты каждый раз объясняешь контекст заново.

4. Сделай тестовый запрос по R.A.C.E.T.

Возьми реальную задачу из своей работы. Сформулируй по формуле из прошлого блока. Посмотри на разницу с обычным запросом.

5. Подключи Google Drive (опционально)

В настройках Claude можно подключить Google Drive и Gmail. Тогда Claude может читать твои документы напрямую. Не обязательно, но удобно.

6. Попробуй итерацию

Возьми любой ответ Claude. Скажи что не так. Попроси переделать конкретный элемент. Убедись, что AI работает в диалоге, а не в режиме «одного запроса».

7. Сохрани эту страницу в закладки

База знаний пополняется. Следующие блоки — про Claude Code, контент-систему и практические кейсы. Возвращайся.

Итого

Аккаунт + Project + первый запрос по R.A.C.E.T. — это всё, что нужно для старта. Остальное придёт в процессе.
