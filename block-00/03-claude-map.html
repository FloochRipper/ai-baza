Карта Claude

Claude — продукт компании Anthropic. Существует в нескольких форматах: веб-интерфейс на claude.ai, мобильное приложение, API для разработчиков и Claude Code — инструмент для работы с кодом прямо в терминале.

Тарифы: что реально нужно

ТарифЦенаДля кого
Free0$Попробовать. Лимиты на количество сообщений.
Pro$20/месРегулярная работа. Приоритет в пиковое время, больше токенов.
Max$100/месИнтенсивная работа с кодом, большие контексты.
Teamот $25/челКомандное использование.
⚡ Что выбрать на старте

Начни с Free — пойми, нужно ли тебе вообще. Если начнёшь использовать регулярно, переходи на Pro. Max нужен, если упрёшься в лимиты при работе с кодом.

Главная фича Claude — Projects

Project — это папка с контекстом. Ты один раз загружаешь туда всё про свой проект: кто ты, чем занимаешься, какая аудитория, примеры текста, правила работы. И каждый раз, когда открываешь этот Project, — Claude уже всё знает.

Без Projects
Каждый новый чат начинаешь с объяснений. «А, мы же делали лендинг для психолога» — и ты снова всё объясняешь с нуля.
С Projects
Зашёл в Project «Мой бренд» — Claude уже знает кто ты, над чем работаете и какие правила. Объяснять не нужно.

Модели Claude

Anthropic регулярно выпускает новые версии. На момент написания актуальны:

МодельХарактеристика
Claude SonnetБаланс скорости и качества. Рабочая лошадка.
Claude OpusСамая мощная. Медленнее и дороже.
Claude HaikuБыстрая и дешёвая. Для простых задач.
Аналогия

Sonnet — как обычный автомобиль. Opus — как спорткар: мощнее, но дороже и медленнее разгоняется. Haiku — как скутер: быстро доехать из А в Б.
