Если хочешь делать сайты и инструменты — иди в Claude Code. Если главная задача — контент и аудитория — иди в Контент-систему. Оба блока независимы.

Что меняется в Claude Code

Block-00 был про то как работать с Claude в чате — claude.ai в браузере. Если выбираешь путь Claude Code, переходишь в другой мир: AI становится твоим разработчиком, который сидит в редакторе кода (VS Code) и работает с реальными файлами на твоём компьютере.

Чат Claude.ai (block-00) Claude Code (block-01)
Где работаешь В браузере на claude.ai В VS Code на своём компьютере
Что делает Claude Отвечает текстом, ты копируешь и применяешь сам Сам редактирует файлы, создаёт сайты, ставит пакеты
Что ты получаешь Тексты, идеи, объяснения Реальные работающие сайты, боты, инструменты
Уровень навыка Никаких технических навыков не нужно Не нужно уметь кодить, но придётся освоить минимум: терминал, файлы, GitHub

Это не «следующий уровень» в смысле сложности — это другая мастерская. В block-01 разбираем по шагам: от установки VS Code до запуска агента в Telegram.

Параллельно есть отдельная страница с готовыми промптами для Claude Code — cc-prompts.html. 50 промптов которые можно копировать и использовать сразу.

Главная мысль

Понимать архитектуру важнее, чем знать каждую команду. AI-инструменты меняются каждые несколько месяцев. Меняться вместе с ними проще, если понимаешь принципы, а не только кнопки.

Финальная аналогия

Водитель, который понимает как работает машина, справится с любой моделью. Тот, кто запомнил только одну кнопку — потеряется на другом автомобиле.
