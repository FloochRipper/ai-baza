Словарь терминов

Термины, которые встретятся в следующих разделах. Здесь — простыми словами, с аналогиями.

AI и модели

LLM

Большая языковая модель. Claude, ChatGPT, Gemini — это LLM. Особенно хорошо работает с текстом, смыслом, инструкциями, кодом и объяснениями.

Аналогия

Как очень начитанный собеседник, который прочёл миллионы книг и может поддержать любую тему.

Промпт

Текст-команда, которую ты пишешь AI. Главный инструмент получения нужного результата.

Аналогия

Как рецепт для повара: написал «торт» — получишь что попало. Написал «шоколадный торт с вишней, 3 слоя» — получишь именно это.

Токен

Единица обработки текста AI. Ориентир — 1 слово ≈ 1–2 токена. За токены платят деньги.

Аналогия

Как минуты на телефоне: чем дольше говоришь — тем больше тратишь.

R.A.C.E.T.

Формула промпта: Role, Action, Context, Expectation, Tone. Подробнее — в разделе про промптинг.

Агент (AI-агент)

AI, который сам выполняет задачи: ищет информацию, пишет код, отвечает на вопросы. Делает цепочку шагов сам.

Аналогия

Как личный помощник, который работает без перерывов и не забывает задачи.

Вайбкодинг

Ты говоришь AI, что хочешь — он пишет код за тебя. Никакого программирования руками.

Аналогия

Как заказать еду в ресторане: говоришь официанту что хочешь, а повар готовит.

Разработка и инфраструктура

Терминал

Программа для текстовых команд. На Mac — встроена в систему (приложение «Терминал» или «Terminal»), на Windows — называется PowerShell. Через терминал запускают сайты, ставят пакеты, общаются с GitHub.

Аналогия

Кабина пилота с приборной панелью: вместо кнопок ты пишешь команды. Звучит страшно, на деле — несколько команд решают всё.

Пакеты (зависимости)

Готовые куски чужого кода которые подключаются к проекту. Кто-то уже написал «работу с датой», ты просто подключаешь — не пишешь с нуля. Пакеты ставятся командой npm install и хранятся в папке node_modules.

Аналогия

Лего: вместо вырезания кубиков из дерева — берёшь готовые из набора и собираешь свой замок.

Язык программирования

Язык на котором пишется код. Самые распространённые сегодня: JavaScript (для сайтов и веб-приложений), Python (для AI, ботов, скриптов), HTML и CSS (для веба, простые в изучении). Claude знает все основные языки — ты в большинстве случаев сам можешь не знать, на чём пишется твой проект.

Стек

Набор технологий которые используются в проекте. Например, «React + Node.js + PostgreSQL» — это стек: фреймворк для интерфейса, серверный язык, база данных. Когда Claude спрашивает «какой у тебя стек?» — он спрашивает на чём построен проект.

Аналогия

Как набор инструментов в мастерской: молоток, отвёртка, дрель. Каждый под свою задачу, вместе они образуют твой рабочий инструментарий.

Репозиторий

Папка проекта на GitHub с историей всех изменений. Хранит каждую версию каждого файла за всё время существования проекта. Сокращённо часто называют «репо».

Коммит

Одно сохранение в истории проекта с подписью что изменилось. Аналог «сохранить» в игре — точка к которой можно вернуться. Хорошие коммиты делаются партиями: сделал работающую фичу — коммит, починил баг — коммит.

Ветка (branch)

Параллельная линия истории проекта. Главная ветка обычно называется main. Хочешь экспериментально попробовать что-то — создаёшь ветку, работаешь там. Получилось — сливаешь в main, не получилось — выкидываешь.

Worktree

Дополнительная папка проекта на той же машине, привязанная к другой ветке. Позволяет запустить несколько Claude Code параллельно — каждый в своей копии, не мешая друг другу.

Dev-сервер

Локальный сервер для разработки, работает на твоём компьютере. Открывается по адресу localhost:8080 или похожему — видишь свой сайт «как настоящий», но в интернет он пока не выложен.

Линтер

Программа которая проверяет код на ошибки и нарушения стиля. Запускаешь — получаешь список замечаний. Популярные: ESLint (JavaScript), Prettier (форматирование), Stylelint (CSS).

Скилл

Готовая инструкция на конкретную задачу. Вызывается через /команду внутри Claude Code.

MCP

Model Context Protocol — способ подключать к Claude внешние инструменты: браузер, файловую систему, базы данных.

CLAUDE.md

Файл правил проекта. Claude читает его при каждом запуске сессии — там лежит контекст, правила и инструкции.

Push

Отправка сохранений в облако (GitHub). Защита от поломки компьютера.

Деплой

Когда выкладываешь свой сайт в интернет — его может увидеть любой человек.

Аналогия

Как открытие магазина: вывеска повешена, двери открыты — заходите.

Веб и технологии

Фронтенд

Всё, что видит пользователь: кнопки, тексты, картинки, цвета.

Аналогия

Витрина магазина — красивая, привлекает покупателей.

Бэкенд

Скрытая часть сайта: где хранятся данные, проверяются пароли, считаются заказы.

Аналогия

Кухня ресторана и склад — посетители не видят, но без них ничего не работает.

API

Способ, которым программы разговаривают друг с другом и передают данные.

Аналогия

Официант в ресторане: берёт твой заказ, несёт на кухню, приносит блюдо.

Хостинг

Компьютер в интернете, на котором живёт твой сайт 24/7.

Аналогия

Аренда квартиры для сайта: платишь за место, сайт там «живёт».

Домен

Имя твоего сайта, которое люди вводят в браузере. Например: mybrand.ru.

DNS-записи

Настройки которые говорят интернету «этот домен ведёт на этот хостинг». Когда покупаешь домен и подключаешь его к Vercel или Netlify — добавляешь DNS-записи в панели регистратора. Обычно занимает от 5 минут до часа чтобы сайт открылся по новому адресу.

Аналогия

Как табличка на двери офиса: говорит почтальону куда нести письма для этой компании. DNS делает то же для интернет-трафика.

MVP

Минимальная рабочая версия продукта. Сначала самокат, потом машина.

Фреймворк

Набор готовых инструментов, чтобы не писать всё с нуля. Next.js, React, Vue — это фреймворки.

Аналогия

Готовый каркас дома: стены уже стоят, тебе остаётся сделать ремонт и расставить мебель.

Парсинг

Робот заходит на сайты и собирает нужную информацию автоматически.

Аналогия

Помощник, который обходит 50 магазинов и записывает все цены в табличку за тебя.
