# Гайд конкурента — структура и содержание

## Что внутри (7 страниц)

1. **Обложка** — "Гайд по Claude. Полная инструкция для новичка. Установка · Регистрация · Функции · Расширения". Плашки: 200K токенов, #1 конкурент ChatGPT, 2023 год основания.
2. **Блок "Читаешь из России? Сначала сюда"** — VPN (у конкурента Outline/Mullvad/NordVPN — НЕ берём, см. ниже), иностранный номер (sms-activate.org, 5sim.net, 20-50₽), eSIM альтернатива (Airalo от $1.5). Предупреждение: включить VPN ДО открытия claude.ai.
3. **Что такое Claude и зачем нужен** — карточки: тексты, документы, код, стратегия, анализ, редактура.
4. **Сравнительная таблица Claude vs ChatGPT** — контекст, работа с файлами, стиль, изображения, плагины, цена, для чего лучше. Вывод: использовать оба.
5. **Пошаговая регистрация — 6 шагов:**
   1. Включи VPN (США/Германия/Франция, проверь 2ip.ru)
   2. Купи иностранный номер (sms-activate или 5sim)
   3. Открой claude.ai → Sign Up → email
   4. Подтверди email
   5. Введи номер → получи SMS → введи код
   6. Имя → Skip → внутри
6. **Тарифы** — Free / Pro $20 / Team $25×чел.
7. **Коннекторы** — Google Drive, Gmail, Slack, Google Calendar, Asana/Jira, Make/Zapier. Settings → Connectors.
8. **Claude Code vs Cowork** — две карточки "следующий уровень".
9. **Humanizer skill** — инструкция добавить через GitHub SKILL.md в Projects. (УСТАРЕЛО: сейчас скиллы иначе)
10. **Projects** — таблица: контент / бизнес / документы / код / Humanizer.
11. **Чек-лист первого дня** — 9 пунктов.
