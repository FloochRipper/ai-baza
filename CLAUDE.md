# CLAUDE.md — Платформа "База знаний"

---

## ЧТО ЭТО ЗА ПРОЕКТ

Платформа-база знаний по AI и вайбкодингу. Лид-магнит + трипвайер в одном продукте.
Текущая стадия: HTML-прототип, развиваем в полноценную платформу.

**Связанный проект:** `../kontent-zavod-nikita/` — контент для соцсетей.
Оттуда идёт трафик сюда через CTA в Reels/постах/Threads.

---

## АУДИТОРИЯ

Новички, которые уже что-то слышали или пробовали Claude / Claude Code и хотят копнуть глубже.
Наша задача — довести их до среднего уровня через блоки базы.
Пишем простым языком, без жаргона по умолчанию, объясняем на пальцах.

### Принципы
- НЕ курс в записи — живая база знаний которая пополняется
- Делается самому через вайбкодинг — это демонстрация навыка
- Одна платформа — разные уровни доступа
- Узко и конкретно по каждому блоку

## СТЕК И СТРУКТУРА

**Стек:** чистый HTML/CSS/JS, без фреймворков.

**Принцип структуры:**
- `index.html` — главная с навигацией
- `block-NN.html` — отдельная страница под каждый блок базы
- `100-prompts-pro.html` — часть базы знаний (каталог промптов)
- `styles.css`, `scripts.js` — общие стили и скрипты
- `fonts/` — self-host шрифты (без Google Fonts)
- `screenshots/` — картинки к инструкциям
- `_sources/` — исходники будущих страниц: md-файлы с контентом, которые ещё не сверстаны в HTML. Когда накоплен материал для новой страницы — кладём сюда, потом верстаем.
- `_headers` — Netlify-конфиг для кэша статики

**Куда можем вырасти:** Next.js/Astro, авторизация, платёжка для трипвайера.
Решение о стеке принимаем когда упрёмся в лимиты статики.

## СТИЛЬ ТЕКСТА НА ПЛАТФОРМЕ

- Разговорный русский, короткие абзацы
- Без жирного текста
- Без маркированных списков в тексте статей (можно в инструкциях)
- Начинать с конкретной сцены/факта
- Статьи от первого лица (я, мне), не "Никита делает"
- Запрещённые слова: погружение, на стыке, уникальная методика, пассивный доход, гарантированный результат
- Авторские фразы НЕ ТРОГАТЬ: "стоит немного подзаморочиться", "я ведь знаю что вам не охота"

## РАБОЧИЙ ПРОЦЕСС

- Перед созданием/удалением файла — скажи что планируешь, потом делай
- При работе с библиотекой/фреймворком — фетчим актуальную доку через Context7 MCP
- Перед фиксом бага — ищем корневую причину, не заплатку
- Если задача неочевидная — задавай уточняющие вопросы

### Паттерны оптимизации (закрепились)
- Картинки: PNG → JPG, lazy loading
- Шрифты: self-host в `fonts/`, без Google Fonts
- Статика: кэш через `_headers`
