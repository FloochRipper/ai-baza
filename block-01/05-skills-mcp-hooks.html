Расширения Claude Code: обзор

По умолчанию Claude Code умеет читать файлы, писать код, запускать команды в терминале. Это уже много. Но настоящая мощь начинается когда подключаешь расширения. Их четыре вида — у каждого своя задача.

Эта статья — обзор и карта местности. Каждое расширение разбираем подробно в отдельной статье. Читай по порядку или сразу в нужную.

Четыре расширения

Расширение Что делает Когда нужно
Скиллы Готовые инструкции под задачу, подгружаются автоматически Делаешь похожие задачи много раз, есть свод правил которым нужно следовать
MCP Подключение внешних сервисов — браузер, базы данных, поиск, мессенджеры Нужно чтобы Claude умел взаимодействовать с чем-то снаружи папки проекта
Хуки Автоматические действия на события (звук, тесты, форматирование, защита от опасного) Хочешь автоматизировать рутину или поставить страховку от ошибок
Плагины Готовые наборы скиллов + MCP + хуков в одной коробке, ставятся одной командой Хочешь установить готовый набор инструментов или поделиться своим набором с командой

Скиллы — коротко

Скилл — это готовая инструкция в папке проекта, которую Claude применяет когда замечает подходящую задачу. Например, ты регулярно пишешь посты в Telegram-канал в своём стиле — создаёшь скилл, и Claude следует правилам автоматически.

Ключевая особенность: скилл подгружается только когда нужен. Можно держать десятки скиллов, контекст не переполняется.

Подробно про скиллы → 05a

MCP — коротко

MCP (Model Context Protocol) — стандарт подключения внешних сервисов. Без MCP Claude видит только папку проекта. С MCP — может искать в интернете, читать твою базу данных, открывать сайты, отправлять сообщения в Telegram.

Аналогия: Claude Code — компьютер, MCP — USB-хаб. Каждый MCP-сервер — адаптер к конкретному сервису.

Подробно про MCP → 05b

Хуки — коротко

Хук — автоматическое действие при событии. Claude закончил отвечать → играет звук. Сохранил файл → запускаются тесты. Хочет выполнить опасную команду → блокируется.

Самый практичный хук на старте — звуковое уведомление: можно отойти от экрана и услышать когда задача готова.

Подробно про хуки → 05c

Плагины — коротко

Плагин — это упакованный набор скиллов, MCP, хуков и субагентов. Команда /plugin открывает менеджер с официальным маркетплейсом Anthropic — оттуда ставится готовый набор инструментов одной командой.

Можно создать свой плагин и поделиться с командой — все коллеги получают одинаковый набор инструментов через /plugin install.

Подробно про плагины → 05d

Как они работают вместе

Скиллы, MCP и хуки — не альтернативы, а команда. Каждое решает свою задачу, и их сильнее всего использовать вместе.

Реальный сценарий

Ты подключаешь MCP для Telegram (внешний сервис), пишешь скилл «отвечать клиентам» со своими правилами, ставишь хук на уведомление в Telegram когда Claude закончил. Получается система: клиент пишет → Claude видит через MCP → отвечает по правилам скилла → ты получаешь уведомление в свой канал.

Не пытайся освоить всё сразу. Стандартный путь развития:

  1. Сначала хуки — поставь звук на завершение задачи. Это занимает 5 минут и сразу делает работу удобнее
  2. Потом MCP — подключи Exa для поиска и Context7 для документации. Большинству хватает этих двух
  3. Потом свои скиллы — когда заметишь что объясняешь Claude одни и те же правила третий раз — пора создавать скилл
Итого

Скиллы — для повторяющихся задач со своим стилем. MCP — для подключения внешних сервисов. Хуки — для автоматических действий на события. Каждое — отдельная статья с подробностями, конкретными примерами и промптами.

Хочешь собрать что-то конкретное?

Разберём твою задачу за 30 минут — что собирать, с чего начать, какой стек, какие подводные камни. По итогу у тебя будет понятный план действий.
