Что дальше: дорожная карта

Прошёл все 14 статей базы — теперь у тебя в руках инструмент, которого ещё пять лет назад не существовало. Можно делать сайты, ботов, автоматизации — то на что раньше уходили месяцы и тысячи долларов разработчику.

Но это только основа. Дальше есть два пути развития, и оба интересные. Можно идти обоими параллельно или сначала одним, потом другим — последовательность не критична.

Путь 1: запустить продукт в мир

Если цель — сделать рабочий продукт, который кто-то будет использовать (или покупать). Знания инструментов уже есть, дальше — практика на живых задачах. Что обычно нужно следующим:

  • Свой домен — чтобы ссылка не была vash-proekt.vercel.app
  • База данных — если у проекта есть пользователи или данные которые нужно хранить
  • Авторизация через Google, Apple, email — чтобы пользователи могли создавать аккаунты
  • Платежи — Stripe, ЮKassa, Tinkoff (зависит от рынка)
  • Telegram-бот — для общения с клиентами или автоматизации записи
  • Аналитика — Plausible, Yandex Metrica, чтобы понимать что делают пользователи
  • Email-рассылка — Resend, Sendgrid для уведомлений и маркетинга

Каждый из этих кирпичиков — отдельная тема, на каждую уходит день-два если разбираешься через Claude Code. Идти лучше под конкретную задачу: не «надо изучить базы данных», а «нужна форма записи которая сохраняет в Google Sheets — разберём как».

Кому это путь: хочешь делать продукты — лендинги, мини-приложения, боты. Готов запустить и показать миру даже сырое.

Путь 2: прокачать инструменты на максимум

Если цель — стать мастером Claude Code как инструмента. Превратить его из «помощника» в полноценную систему которая работает почти автономно. Дальнейшие темы:

  • Свои скиллы — собрать библиотеку под свои регулярные задачи (контент, отчёты, ревью)
  • Плагины из маркетплейса — поставить готовые наборы из официального каталога Anthropic (см. статью 05d)
  • Кастомные MCP-серверы — подключение своих систем (CRM, базы данных, внутренние API)
  • Хуки для автоматизации — тесты, форматирование, уведомления — всё само срабатывает
  • Worktrees + Agent Teams — несколько Claude работают параллельно над разными частями
  • Headless-режим — Claude работает по расписанию без твоего участия (ночные задачи)
  • Claude на VPS — агент работает 24/7, ты управляешь с телефона
  • Свои AI-агенты — те самые Telegram-боты для клиентов из статьи 13

Это путь для тех, кто хочет масштабировать своё время через AI. Не «я сделал один сайт», а «у меня работают пять агентов на разных задачах».

Кому это путь: уже что-то выпустил, хочешь делать больше с тем же количеством рук. Или превратить процессы своего бизнеса в полу-автоматические.

Не нужно выбирать что-то одно

Эти два пути не противоречат друг другу. Большинство практиков идут параллельно: сегодня запускают лендинг (Путь 1), завтра прокачивают свой workflow через скиллы (Путь 2). Один день фокус на бизнес-результате, другой — на инструменте.

Главное правило развития: учиться через конкретные проекты, не «впрок». Возникла задача — разобрался как Claude Code её решает — применил. Без задачи нет смысла «учить Skills» абстрактно — забудешь через неделю.

Это не финал, это начало

База даёт навык. Что ты с ним сделаешь — зависит только от тебя. Я знаю людей которые после этой базы запустили SaaS-продукт за месяц, и других — кто продолжает «изучать инструменты» полгода без единого результата. Разница не в знаниях, разница в действиях.

Действие, которое отделяет — взять одну конкретную идею из головы и довести до результата. Лендинг для своего бизнеса. Бот для своих клиентов. Автоматизация рутины которая ела два часа в день. Что угодно реальное и небольшое.

Простой следующий шаг

Если не знаешь куда двигаться — открой статью 04 ещё раз и прямо сейчас выбери идею проекта по шаблону «Я создаю X для Y чтобы решить Z». Не идеальную, а реалистичную на эту неделю. И начни вечером.

База нужна была чтобы дойти до этого момента. Дальше — только практика.
