Troubleshooting: что делать если сломалось

Claude Code — инструмент молодой, активно развивается. Иногда что-то ломается, виснет, не загружается. Это нормальная часть процесса. Здесь — список самых частых проблем и быстрых решений.

Совет на старте: если что-то идёт не так — не паникуй и не лезь в настройки. В 80% случаев решает Developer: Reload Window (Cmd+Shift+P → набрать → Enter). Это перезапуск VS Code без потери открытых файлов. Универсальная кнопка.

Проблемы с VS Code и Claude Code

Серый экран или зависание

Что видишь: панель Claude Code стала серой, ничего не отвечает, может крутиться спиннер.

Причина: расширение не успевает обработать команду или потеряло связь с серверами Anthropic.

Решения по порядку:

  1. Закрой вкладку Claude Code и открой новую (Cmd+Shift+Escape).
  2. Если не помогло — Developer: Reload Window (Cmd+Shift+P → Reload Window).
  3. Всё ещё не работает — закрой VS Code полностью, открой заново.
  4. Проверь интернет. Если на нестабильной сети — Claude Code часто капризничает.

История диалогов не загружается

Что видишь: нажимаешь иконку часов — пусто, или висит загрузка, или показывает не те разговоры.

Причина: локальные данные истории повредились или не подгружаются.

Решения:

  1. Reload Window — обычно достаточно.
  2. Если ты в работе и срочно нужно продолжить — скопируй важный контекст из текущего чата в текстовый файл, потом запусти новый чат и вставь.
  3. Если история нужна — попробуй переоткрыть папку проекта (File → Close Folder → File → Open Folder).

Бесконечная загрузка ответа

Что видишь: Claude крутит спиннер «думает» уже минут пять, а ответа нет.

Решения:

  1. Проверь интернет — открой любой сайт. Если медленно загружается — проблема не в Claude.
  2. Нажми Stop (или ESC) чтобы прервать запрос. Сформулируй короче и попробуй ещё раз.
  3. Если задача правда большая — раздели её на несколько маленьких. Claude меньше виснет на коротких запросах.
  4. Reload Window если предыдущее не помогло.

VS Code ест много памяти, тормозит

Что видишь: через несколько часов работы ноутбук начинает шуметь вентилятором, всё подтормаживает.

Причина: длинные сессии, открытые большие файлы, накопленный контекст в нескольких чатах.

Решения:

  1. Используй /compact в текущем чате — освободит контекст.
  2. Закрывай неактивные чаты — они тоже жрут память.
  3. Раз в день перезапускай VS Code полностью — это очищает накопившийся мусор.
  4. Не открывай в одном окне 5 чатов параллельно — лучше пара активных.

Claude отказывается редактировать файлы

Что видишь: просишь сделать правку — Claude отвечает текстом «нужно изменить так-то», но файлы не трогает.

Причина: вероятно ты в Plan Mode (он только планирует) или Ask before edits (ждёт подтверждения).

Решения:

  1. Нажми Shift+Tab чтобы переключить режим. Поищи Edit automatically внизу панели.
  2. Если режим Edit, но всё равно не редактирует — попроси прямо: «Сделай это сейчас, отредактируй файл». Иногда помогает.
  3. Проверь что папка проекта открыта (File → Open Folder), а не отдельный файл.

Проблемы с регистрацией и оплатой

VPN включён, но Claude всё равно не открывается

Решения по порядку:

  1. Проверь страну VPN на 2ip.ru — должна быть США, Великобритания или другая принимаемая.
  2. Очисти cookies браузера (он мог запомнить старый IP).
  3. Попробуй другой VPN-сервер в той же стране.
  4. Открой в режиме инкогнито — иногда расширения мешают.
  5. Если совсем не идёт — попробуй мобильное приложение Claude через VPN на телефоне.

SMS-код не приходит

Решения:

  1. Подожди 5 минут — иногда задержка.
  2. Проверь что страна номера совпадает со страной VPN.
  3. Запроси повторную отправку (обычно есть кнопка через минуту).
  4. Если виртуальный номер уже использовался для Claude — он не работает повторно. Возьми новый.
  5. В крайнем случае — eSIM или Telegram-бот с виртуальной картой и номером в комплекте.

Оплата не проходит

Решения:

  1. Billing Address — должен быть из той же страны что и карта. Если карта американская — адрес из США (можно случайный через генератор).
  2. На карте должно быть достаточно средств плюс небольшой запас (Anthropic иногда списывает $1 для проверки).
  3. Виртуальная карта может быть заблокирована для подписок — попробуй другую.
  4. Проверь что VPN включён и страна совпадает с той с которой регистрировался.
  5. Если ничего не помогает — посредники типа @platipomiru_bot или @WantToPayBot часто справляются.

Аккаунт заблокировали

Что произошло: при входе пишет «account suspended» или похожее.

Решения:

  1. Не паникуй и не создавай новый аккаунт сразу — это может быть автоматическая блокировка из-за смены IP.
  2. Напиши в поддержку Anthropic с того же email что регистрировал. Объясни ситуацию (можно через переводчик).
  3. Если оплачивал картой — деньги вернут.
  4. Если покупал у посредника и аккаунт заблокирован — деньги вернёт только посредник, у которого была история транзакций.
Профилактика блокировки

Не прыгай между странами VPN во время активной сессии. С какой страны зарегистрировался — с той и работай. Если переехал и нужно сменить — напиши заранее в поддержку.

Claude Code специфичные проблемы

Bypass Permissions не сохраняется

Что видишь: включил Bypass, но через час Claude снова спрашивает разрешения.

Решение: попроси Claude настроить через файл (промпт из статьи 02). Когда настройка в settings.json, она сохраняется навсегда. Через переключатель режима — только на текущую сессию.

CLAUDE.md не учитывается

Что видишь: прописал правила в CLAUDE.md, но Claude игнорирует.

Возможные причины:

  1. CLAUDE.md лежит не в корне проекта, а в подпапке. Должен быть в самом верхнем уровне.
  2. Файл стал больше 300 строк — тогда правила в конце могут «теряться». Сократи или вынеси в .claude/rules/.
  3. Правило сформулировано размыто. «Не делай плохо» — не работает. «NEVER delete files without confirmation» — работает.
  4. Открыл проект через File → Open File вместо Open Folder. Тогда контекст папки не подгружается.

MCP-сервер не подключается

Решения:

  1. Проверь интернет — MCP часто работают через сеть.
  2. Попроси Claude показать логи: «Покажи логи последнего подключения MCP-сервера X».
  3. Перезапусти Claude Code (Reload Window).
  4. Проверь что в settings.json правильные credentials, пути к токенам.

Профилактика — чтобы реже сталкиваться

Несколько привычек которые сильно сокращают количество поломок:

Привычка Что даёт
Коммитить чаще, не реже раза в час При любой поломке — точка возврата свежая, не теряешь полдня работы
/clear между задачами Контекст не накапливается, Claude не путается
Раз в день — перезапуск VS Code Память освобождается, ничего не лагает
Не торопись с подтверждениями Прочитай что Claude собирается сделать перед Yes — потом не будешь чинить лишнего
Обновляй расширение Claude Code Многие баги чинят в новых версиях
Универсальный план Б

Если что-то не работает и не знаешь почему: 1) Reload Window. 2) Не помогло — закрой VS Code полностью и открой заново. 3) Не помогло — git commit того что есть, перезагрузи компьютер. 4) Спроси в чате Claude: «Я сделал X, ожидал Y, получил Z. Что могло пойти не так?»
