Первый запуск

Первый запуск может сбить с толку. Пустое окно терминала, непонятные команды, и непонятно с чего начать. Я помню это ощущение — открываешь VS Code, видишь пустоту и думаешь: «ну и что теперь делать».

В этой статье разберём всё по шагам — от установки редактора до первой рабочей сессии. К концу у тебя будет настроенное рабочее место и понимание базовых команд, которые нужны каждый день.

Установка VS Code

VS Code — это профессиональный редактор кода. Бесплатный, работает на Mac, Windows и Linux. Именно внутри него живёт Claude Code — как расширение.

Скачай с официального сайта: code.visualstudio.com. Устанавливается как обычная программа — скачал, запустил, прошёл по шагам установщика.

После установки можно опционально добавить русский интерфейс. Открой вкладку расширений (Cmd+Shift+X на Mac, Ctrl+Shift+X на Windows), найди «Russian Language Pack» от Microsoft и установи. После перезапуска VS Code будет на русском.

Подключение Claude Code

Claude Code ставится как расширение прямо в VS Code. Открой вкладку расширений (Cmd+Shift+X / Ctrl+Shift+X), введи в поиске «Claude Code» и установи расширение от Anthropic.

После установки в боковой панели VS Code появится иконка Claude. Нажми на неё и войди через свой аккаунт на claude.ai. Если аккаунта ещё нет — зарегистрируйся там же, это бесплатно.

При первом входе Claude Code откроет новую сессию в терминале с приглашением claude>. Это значит — всё работает.

Структура проекта

Claude Code всегда работает внутри папки — проекта. Это важно понять с самого начала: он видит только то, что находится в открытой папке. Это не ограничение, а удобство — Claude не лезет куда не просили.

Для каждого нового проекта создавай отдельную папку. В VS Code: File → Open Folder, выбери папку и открой. Внутри этой папки будет жить всё — твои HTML/CSS файлы, скрипты, CLAUDE.md с настройками.

Чистая структура с самого начала экономит много нервов потом. Один проект — одна папка. Без исключений.

Первая команда

Пиши задачу обычным русским языком — никаких специальных синтаксисов учить не нужно. Например:

▸ Первый запрос
Создай простую HTML страницу с заголовком «Привет мир»

При первом использовании Claude Code будет спрашивать разрешение перед каждым действием — прочитать файл, создать файл, изменить файл. Соглашайся: это нормальное поведение по умолчанию для безопасности.

Если постоянные окна с подтверждениями мешают — в следующем разделе разберём как их убрать.

Bypass Permissions — убрать постоянные вопросы

По умолчанию Claude Code спрашивает разрешение буквально на всё — прочитать файл, записать строку, запустить команду. Для новичка, работающего в одиночку над своим проектом, это превращается в постоянный шум.

Есть два способа это починить. Первый — добавить файл настроек в папку проекта. Создай файл .claude/settings.json в корне проекта с таким содержимым:

▸ .claude/settings.json
{
  "permissions": {
    "allow": ["Bash", "Read", "Write", "Edit"]
  }
}

Второй способ — добавить короткий алиас в терминал. Открой файл ~/.zshrc и добавь строку:

▸ ~/.zshrc
alias cc="claude --dangerously-skip-permissions"

После этого набирай cc вместо claude — и никаких вопросов. Чтобы изменения вступили в силу, перезапусти терминал или выполни source ~/.zshrc.

Важно

Bypass Permissions отключает запросы. Используй только в своих проектах — не давай Claude Code с bypass доступ к чужим файлам или системным папкам.

История диалогов

Каждый разговор в Claude Code сохраняется автоматически. Нажми на иконку часов в боковой панели Claude Code — там список всех прошлых сессий.

История привязана к папке проекта. Переключился в другую папку — видишь историю того проекта. Это удобно: вернулся к задаче через неделю, открыл вчерашний разговор и продолжил с места остановки.

Чтобы продолжить конкретный разговор, нажми на него в истории или используй команду /resume.

Команды которые нужны сразу

В Claude Code есть несколько команд, которые используешь каждый день. Вот самые важные:

Команда Когда использовать
/clear Начать разговор с чистого листа (не удаляет файлы, только историю чата)
/compact Сжать историю чата когда Claude начинает «тупить» — убирает лишнее, оставляет суть
/rewind Откатить последние изменения — и файлы, и историю (двойной Escape тоже работает)
/resume Продолжить предыдущий разговор
/voice Включить голосовой ввод
/usage Посмотреть сколько токенов использовал за месяц
Аналогия

Это как Ctrl+Z, только умнее. /rewind откатывает не только то что написал в чате, но и файлы которые Claude Code изменил. Если что-то пошло не так — нажал Esc Esc и всё вернулось.
