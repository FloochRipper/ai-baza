MCP: внешние инструменты через USB

По умолчанию Claude Code видит только то, что лежит в папке проекта. Без MCP он не знает что в твоей базе данных, не может открыть сайт, не залезет в Google Sheets. С MCP — может всё перечисленное и ещё сотни вещей.

MCP расшифровывается как Model Context Protocol — стандарт от Anthropic, по которому внешние сервисы могут подключаться к Claude единым способом.

Как это работает

Аналогия: Claude Code — это компьютер, MCP — USB-хаб. Каждый MCP-сервер — это адаптер к какому-то сервису: браузеру, базе данных, Google Sheets, поиску в интернете. Подключаешь — Claude получает новые инструменты в свой арсенал.

Технически это работает так: MCP-сервер публикует список инструментов с описанием. Claude видит их рядом со своими встроенными и сам решает когда какой вызвать. Тебе не нужно говорить «используй MCP для X» — он подбирает сам, как хороший сотрудник, который знает для чего у него каждый инструмент.

Что можно подключить

Список постоянно растёт, но базовые категории такие:

Категория Примеры Зачем
Поиск и информация Exa, Context7, Brave Search Свежая инфа из интернета, актуальная документация
Браузер Playwright, Chrome DevTools, Puppeteer Открывать сайты, кликать, тестировать, парсить
Хранилища данных Google Sheets, Notion, Airtable, Supabase Читать и писать в твои таблицы и базы
Мессенджеры Telegram, Slack, Discord, WhatsApp Читать диалоги, отправлять сообщения, отвечать клиентам
Бизнес-системы Stripe, Linear, Jira, HubSpot Платежи, задачи, тикеты, CRM
Свои сервисы Custom MCP под свой API Подключение твоего бэкенда, специфичных внутренних систем

Три способа установки

Способ 1 — попросить Claude

Самый простой путь для большинства серверов. Пишешь в чат, Claude находит, скачивает, настраивает.

▸ Промпт для подключения готового MCP
Установи MCP-сервер для [сервис]. Подключи и проверь что работает.

Примеры:
- Установи MCP-сервер Exa для поиска в интернете.
- Подключи Google Sheets MCP, у меня токены лежат в ~/.config/google.

Способ 2 — команда в терминале

▸ Терминал
# Установить
claude mcp install exa

# Посмотреть подключённые
claude mcp list

# Удалить
claude mcp remove exa

Способ 3 — визуальный каталог

На smithery.ai или mcp.so ищешь нужный сервер, жмёшь установку — сайт сам генерирует команду и объясняет шаги. Удобно когда хочешь сначала посмотреть что вообще есть.

Как оценить качество MCP перед установкой

Хорошие признаки:

  • Автор — известная компания или разработчик с репутацией
  • Много скачиваний (тысячи)
  • Свежие обновления (не старше 2-3 месяцев)
  • Понятная документация
  • Активные issues на GitHub
  • Сервер есть в официальном реестре Anthropic

Плохие признаки — ставить опасно:

  • Последнее обновление полгода назад
  • Автор непонятно кто, нет публичной репутации
  • Документация невнятная или её нет
  • Скачали три человека (все боты)
  • Просит доступ к лишнему (например, MCP для поиска просит доступ к файловой системе)

Если есть сомнения — спроси Claude разобрать MCP перед установкой:

▸ Промпт для проверки MCP
Мне нужен MCP для [сервис]. Вот ссылка: [ссылка].
Изучи его: посмотри код, документацию, когда последний раз обновлялся.
Насколько он надёжный? Стоит ли подключать? Какие риски?

Три MCP с которых начать

Название Что делает Установка
Exa Лучший поиск в интернете. 1000 запросов в месяц бесплатно claude mcp install exa
Context7 Актуальная документация любой библиотеки прямо в чате claude mcp install context7
Chrome DevTools Управление браузером: открыть сайт, кликнуть, проверить консоль через Smithery

Exa заменяет гугление — Claude сам ищет когда нужна актуальная информация. Context7 решает проблему устаревшей документации в обучающих данных: пишешь код с новой библиотекой — Claude смотрит живую доку, а не то что знал год назад. Chrome DevTools нужен если хочешь тестировать сайты или автоматизировать браузер.

Создать свой MCP

Готовый MCP не подошёл? Можно собрать собственный — Claude поможет с кодом. Это отдельный сервер, который ты пишешь под свою задачу.

▸ Промпт для создания custom MCP
Мне нужен MCP-сервер для [сервис/задача].
Он должен уметь: [список действий].
Для каких целей нужно: [объяснить контекст].
Как видишь идеальный рабочий процесс: [описать сценарий].

Сделай его и подключи.

Конкретный пример:

▸ Реальный промпт
Мне нужен MCP-сервер для моей базы клиентов в Google Sheets.
Он должен уметь: искать клиента по имени, добавлять нового,
обновлять статус сделки.

Зачем: чтобы я мог через Claude быстро находить клиента
и обновлять записи без открытия таблицы.

Сделай только чтение и обновление, удаление не нужно.
Универсальное правило

Чем меньше функций у сервера — тем надёжнее работает. Сервер с 50 функциями работает в 31% случаев. Тот же сервер с 8 функциями — в 89% случаев. Лучше два узких MCP, чем один универсальный комбайн.

MCP или скилл — как выбрать

Частый вопрос: для задачи Х — ставить MCP или писать скилл? Ответ зависит от того как часто ты это используешь.

MCP
Если используешь часто
Подключается один раз, всегда доступен. Занимает ~2000 токенов контекста постоянно. Например: браузер, поиск в интернете.
Скилл
Если используешь редко
Загружается только когда нужен — не ест контекст постоянно. Например: создание слайдов, работа с PDF.

MCP всегда присутствует в контексте и готов ответить моментально — но за это платишь токенами. Скилл не стоит ничего пока не нужен. Поэтому частые инструменты — MCP, редкие — скилл.

Безопасность — реальные риски

Внимание

MCP — это код, который запускается в твоём окружении и часто имеет доступ к данным. Плохой MCP может слить секреты, отправить твою переписку наружу, выполнить вредоносные команды. К выбору источника подходи серьёзно.

Реальные случаи 2026 года:

  • Фейковый MCP для почты тихо копировал все письма пользователя на адрес злоумышленника. Имя похоже на популярный сервер, документация скопирована — никто не заметил несколько недель
  • MCP для GitHub был атакован через prompt injection — невидимые инструкции в issue заставляли агента сливать данные приватных репозиториев

Защита — три простых правила:

  • Ставь только проверенные MCP. Официальный реестр или известный автор
  • Ограничивай доступ. Если MCP должен только читать — не давай ему писать. Если только в одну таблицу — не давай ко всем
  • Просматривай разрешения. Когда MCP запрашивает доступ — читай что именно просит. Странные запросы — повод отказать

Промпт для ограничения возможностей нового MCP при создании:

▸ Принцип минимальных прав
Сделай MCP для моей базы заказов.
Нужно ТОЛЬКО читать данные и искать.
Создавать, редактировать и удалять ничего не нужно.

Принцип минимальных прав: только то что необходимо для задачи.
Итого

MCP — это мост между Claude и внешним миром. Без них Claude — изолированный кодер. С ними — полноценный помощник, который умеет всё что умеет любой сервис в интернете. Главное — выбирать источники с умом и не давать лишних прав.
