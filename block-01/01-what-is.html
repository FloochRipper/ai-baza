Что такое Claude Code

Открываю VS Code, пишу одну фразу: «Сделай страницу с навигацией, тёмный фон, оранжевый акцент, вот структура» — и Claude Code начинает работать. Открывает файлы, пишет код, создаёт папки. Через несколько минут страница уже в браузере.

Это называется вайбкодинг. Claude Code — его главный инструмент. Здесь объясню как это работает и что можно сделать.

Чем отличается от обычного Claude

Claude.ai — браузер или приложение
Просто чат — ты копируешь код руками и вставляешь сам. Файлы и папки не видит, только то что ты ему отправил. Не может редактировать файлы на твоём компьютере. Хорошо для вопросов, объяснений, написания текста.
Claude Code в VS Code
Видит весь проект — все файлы и папки. Сам редактирует файлы, создаёт новые, удаляет. Запускает команды в терминале, делает git commit, устанавливает пакеты. По сути — полноценный AI-разработчик прямо в твоём проекте.

Простая аналогия: приложение — это как позвонить программисту по телефону и диктовать код. Claude Code в VS Code — это как посадить программиста прямо за твой компьютер.

Для реальной работы с кодом и проектами — однозначно Claude Code в VS Code намного мощнее.

Где запускать Claude Code

Claude Code работает в нескольких местах. На сайте claude.ai — открываешь в браузере, там есть вкладка с Claude Code. Через настольное приложение Claude — скачивается отдельно и работает без браузера. И внутри VS Code — как расширение в редакторе кода.

Первые два варианта проще в старте, но ограничены: там Claude Code видит только то, что ты вставил в чат руками. Нет доступа к файлам на компьютере, нельзя запускать команды, нельзя работать с реальным проектом.

VS Code — это то самое рабочее место, о котором пишут все кто серьёзно работает с Claude Code. Он сидит прямо внутри папки проекта, видит все файлы, пишет и редактирует их напрямую. Именно это делает его настоящим ИИ-коллегой, а не просто умным чатом.

Рекомендация

Для реальной работы — только VS Code. Сайт и приложение удобны чтобы быстро спросить что-то или протестировать идею, но строить проекты будешь именно через VS Code.

Что можно сделать

Самый частый вопрос, который я слышу: «Но я же не программист. Что я вообще буду с этим делать?» Вот несколько реальных примеров без единой строчки кода с твоей стороны.

Личный сайт — портфолио, визитка, страница с проектами. Говоришь Claude Code что хочешь видеть, описываешь стиль, он собирает. Готово за несколько часов, не за несколько недель.

Telegram-бот для клиентов — отвечает на частые вопросы, принимает заявки, отправляет уведомления. Не нужно нанимать разработчика под такую задачу.

Таблица, которая сама обрабатывает данные. Загружаешь CSV с продажами — скрипт считает итоги, фильтрует, форматирует и выдаёт готовый отчёт. Больше никакой ручной сортировки.

Скрипт для порядка в файлах. Сотни фотографий в одной папке? Скрипт разложит по датам, переименует по шаблону, удалит дубли.

Форма обратной связи на сайт. С отправкой на почту, с защитой от спама, с подтверждением для пользователя — всё это не требует знания PHP или Node.js, если рядом Claude Code.

Вайбкодинг — что это

Термин придумал Andrej Karpathy — один из создателей Tesla Autopilot и сооснователей OpenAI. Он описал подход, при котором разработчик перестаёт думать о синтаксисе и деталях реализации, а сосредотачивается на том, что именно должно получиться.

Раньше чтобы сделать веб-сайт, нужно было знать HTML, CSS, JavaScript — а лучше ещё и какой-нибудь фреймворк поверх. Чтобы написать бота — Python и библиотеки к нему. Без этого никак. Это был входной барьер, который отсекал всех не-программистов.

Вайбкодинг этот барьер убирает. Теперь нужно уметь объяснять задачу. Точно, конкретно, с деталями — но на обычном языке. Не «сделай сайт», а «сделай страницу с тёмным фоном, шапкой с логотипом слева и тремя ссылками справа, под ней большой заголовок и две колонки текста».

«Вайб» в названии — это ощущение правильного направления. Ты видишь, что получается, чувствуешь где хорошо а где надо подправить, и направляешь процесс. Claude Code пишет код. Ты рулишь.

Как установить

Установка занимает минут десять. Нужны две вещи: VS Code и расширение Claude Code.

Шаг первый — скачать VS Code. Это бесплатный редактор кода от Microsoft, работает на Mac, Windows и Linux. Идёшь на code.visualstudio.com и жмёшь Download.

Шаг второй — установить расширение Claude Code. Открываешь VS Code, нажимаешь Ctrl+Shift+X (или Cmd+Shift+X на Mac) — это панель расширений. В поиске пишешь «Claude Code», находишь расширение от Anthropic и жмёшь Install.

Шаг третий — авторизация. После установки расширение попросит войти через аккаунт claude.ai. Нажимаешь кнопку, браузер открывает страницу входа, подтверждаешь — и готово.

Шаг четвёртый — первый запуск. Открываешь терминал внутри VS Code через Ctrl+` (это обратный апостроф, клавиша под Escape). Там уже активен Claude Code и ждёт первой команды.

Важно

Нужен аккаунт Claude Pro или выше. Бесплатный план не даёт доступ к Claude Code.

Голосовой ввод

Печатать длинные задачи руками — медленно и неудобно. Голосом работать с Claude Code намного быстрее. Это одна из самых недооценённых фишек — стоит попробовать один раз, и обратно уже не хочется.

Поток выглядит так: нажал кнопку → наговорил задачу → отпустил → текст появился в поле → нажал Enter → Claude Code начал работать.

Первый вариант — приложение Handy. Бесплатное, работает на Mac и Windows. Горячая клавиша в любом месте системы — нажал, сказал, отпустил, текст вставился куда надо.

Второй — Whisper Flow, для Mac. Двойное нажатие правого Shift — и голос включается, ещё раз — текст вставляется. Очень точно распознаёт, работает шустро. Есть бесплатный пробный период, дальше подписка.

Третий — Aquavoice, тоже для Mac, бесплатный базовый план. Принцип тот же. Для старта хватает.

Есть ещё встроенный /voice прямо в Claude Code — без сторонних приложений, работает из коробки. Удобно если ничего не установлено.

Итого

Claude Code — это не чат. Это ИИ-коллега который сидит в твоём проекте и делает работу руками. Ты объясняешь, он строит.
