Подготовка к работе с Claude Code

Открываю VS Code, пишу одну фразу: «Сделай страницу с навигацией, тёмный фон, оранжевый акцент, вот структура» — и Claude Code начинает работать. Открывает файлы, пишет код, создаёт папки. Через несколько минут страница уже в браузере.

Это называется вайбкодинг — способ создавать программы, описывая словами что должно получиться, а не как это запрограммировать. Раньше нужно было знать языки программирования, теперь достаточно объяснить идею. Claude Code — главный инструмент для этого. Здесь разберём, чем он отличается от браузерного чата, где его запускать — и установим всё нужное.

Чем отличается от обычного Claude

claude.ai в браузере — это чат. Умный, отвечает на вопросы, может написать кусок кода. Но дальше не идёт: он не знает, какие файлы у тебя на компьютере, и сам ничего с ними сделать не может. Claude Code — другой уровень. Разберём подробно ниже.

Где запускать Claude Code

Главное разделение — не где запускать, а какой продукт используешь: claude.ai (чат) или Claude Code (инструмент).

Claude.ai — браузер или чат-приложение

  • Это просто чат — ты копируешь код руками, вставляешь сам
  • Файлы и папки не видит — только то, что ты ему отправил
  • Не может сам редактировать файлы на твоём компьютере
  • Хорошо для вопросов, объяснений, написания текста

Claude Code — приложение или расширение VS Code

  • Видит твой проект целиком — все файлы и папки
  • Сам редактирует файлы, создаёт новые, удаляет
  • Запускает команды в терминале (программа для текстовых команд — у Mac встроена в систему, у Windows это PowerShell)
  • Может делать git commit (фиксировать изменения), устанавливать пакеты (готовые библиотеки кода которые проект использует) и т.д.
  • По сути — полноценный AI-разработчик в твоём проекте

Claude Code доступен как отдельное приложение для Mac и Windows, а также как расширение VS Code. Разница простая: в desktop-версии у тебя только окно чата, без редактора кода. Чтобы посмотреть что Claude изменил в файле — нужно открывать его отдельно. В VS Code наоборот: чат справа, файлы слева, изменения видишь прямо в коде — что добавилось зелёным, что удалилось красным.

В этом разделе

Мы работаем через VS Code — там сразу видно что Claude делает, и удобно поправить если что-то не так.

Как установить

Установка занимает минут десять. Нужны две вещи: VS Code и расширение Claude Code.

Шаг первый — скачать VS Code. Это бесплатный редактор кода от Microsoft, работает на Mac, Windows и Linux. Идёшь на code.visualstudio.com и жмёшь Download.

Шаг второй — установить расширение Claude Code. Открываешь VS Code, нажимаешь Ctrl+Shift+X (или Cmd+Shift+X на Mac) — это панель расширений. В поиске пишешь «Claude Code», находишь расширение от Anthropic и жмёшь Install.

Шаг третий — авторизация. После установки расширение попросит войти через аккаунт claude.ai. Нажимаешь кнопку, браузер открывает страницу входа, подтверждаешь — и готово.

Шаг четвёртый — открыть панель Claude Code. Два способа.

Через Command Palette: нажми Cmd+Shift+P на Mac или Ctrl+Shift+P на Windows, напиши «Claude Code: Open in Side Bar» и нажми Enter — панель откроется справа.

Через иконку: найди оранжевый логотип Claude в боковой панели VS Code и кликни на него.

Важно

Нужен аккаунт Claude Pro или выше. Бесплатный план не даёт доступ к Claude Code.

Лайфхак: голосовой ввод

Печатать длинные задачи руками — медленно и неудобно. Голосом работать с Claude Code намного быстрее. Это одна из самых недооценённых фишек — стоит попробовать один раз, и обратно уже не хочется.

Поток выглядит так: нажал кнопку → наговорил задачу → отпустил → текст появился в поле → нажал Enter → Claude Code начал работать.

Первый вариант — приложение Handy. Бесплатное, работает на Mac и Windows. Горячая клавиша в любом месте системы — нажал, сказал, отпустил, текст вставился куда надо.

Второй — Whisper Flow, для Mac. Двойное нажатие правого Shift — и голос включается, ещё раз — текст вставляется. Очень точно распознаёт, работает шустро. Есть бесплатный пробный период, дальше подписка.

Третий — Aquavoice, тоже для Mac, бесплатный базовый план. Принцип тот же. Для старта хватает.

Есть ещё встроенный /voice прямо в Claude Code — без сторонних приложений, работает из коробки. Удобно если ничего не установлено.

Итого

Claude Code — это не чат. Это ИИ-коллега который сидит в твоём проекте и делает работу руками. Ты объясняешь, он строит.

Хочешь собрать что-то конкретное?

Разберём твою задачу за 30 минут — что собирать, с чего начать, какой стек, какие подводные камни. По итогу у тебя будет понятный план действий.
