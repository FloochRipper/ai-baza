## Критерии "9 из 10" (объявлены до начала)

1. Все термины введены до того как использованы
2. Каждая статья отвечает на "зачем", "как", "что делать дальше"
3. Каждый абстрактный концепт имеет рабочий пример с конкретикой
4. Промпты есть везде где они полезны
5. Переходы между статьями явные — есть логика последовательности
6. Один термин = одно название везде в базе
7. Реальные кейсы из живых проектов
8. Нет "воды" — каждый абзац несёт обучающую нагрузку
9. Статьи читаются как нарастающая система — после 11-й читатель умеет вайбкодить
10. Тон одинаковый везде — на "ты", по-дружески, без жаргона

**Текущая оценка базы по этим критериям (мой вердикт):** 5–6 из 10. Контент крепкий, но как обучающая система проседает по 1, 3, 4, 5, 9. Цель работы — поднять до 9.
